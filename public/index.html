How FixMyCampus Works

  1. Submit a report. Add a category, location and clear description. You can attach a photo.
  2. Review. Campus staff review the submitted issue.
  3. Action. Staff can change the status to In Progress, Resolved or Rejected.
  4. Track. Reports appear in the recent reports list with their current status and report ID.

This starter project stores data on the server in a JSON file. For production use, add a proper database, student/staff authentication, backups and access controls.
